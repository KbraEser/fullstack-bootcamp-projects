# WiTech Contacts

React + Vite ile yazılmış basit bir kişi rehberi uygulaması. Veri için TanStack Query ve axios kullanılır; testlerde MSW ile API taklit edilir.

## Gereksinimler

- Node.js 18+

## Kurulum ve çalıştırma

```bash
npm install
npm run dev
```

Tarayıcıda adres Vite çıktısında yazar (genelde `http://localhost:5173`).

## Diğer komutlar

| Komut | Açıklama |
|--------|----------|
| `npm run build` | Üretim derlemesi |
| `npm run preview` | Derlemeyi yerelde önizleme |
| `npm run test` | Vitest testleri |
| `npm run lint` | ESLint |
| `npm run wit` | `dev` ve `test` birlikte (concurrently) |

## Teknolojiler

React 18, Vite 5, React Router, TanStack Query, MSW, Vitest, Testing Library.
