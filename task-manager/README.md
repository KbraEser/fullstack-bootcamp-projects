# Task Yönetimi

React ve Vite ile geliştirilmiş basit bir görev panosu. Görev ekleyebilir, ekip üyesi tanımlayabilir ve görevleri “yapılacak” / “yapıldı” sütunları arasında yönetebilirsiniz.


Tarayıcıda Vite’ın verdiği adresi (genelde `http://localhost:5173`) açın.

| Komut | Açıklama |
|--------|----------|
| `npm run dev` | Geliştirme sunucusu |
| `npm run build` | Üretim derlemesi |
| `npm run preview` | Derlemeyi yerel önizleme |
| `npm run test` | Vitest ile testler |
| `npm run lint` | ESLint |

## Teknolojiler

- React 18
- Vite
- Tailwind CSS
- React Hook Form
- react-toastify
- date-fns
- Vitest
